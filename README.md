# 六魂新朝 · Six Souls: A New Dynasty

朕的朝堂里混进了六个 AI。辨清人心，周旋新政，守住皇位与实权。

九幕宫廷策略剧情游戏。可以完整离线游玩，也可在页面顶部输入自己的 API Key 开启 AI 自主对话。可选择加密记住密钥，无需游戏账号，不跳转外链。默认开放 DeepSeek；OpenAI 与 Claude 适配需由部署方在实测后启用。

## 本地启动

需要 Python 3.11 或更新版本。macOS 可双击 `启动新版.command`，首次启动会创建环境并安装依赖，然后在浏览器打开终端显示的地址。

## 魔搭创空间

选择 Docker 方式，仓库根目录包含 Dockerfile，服务监听 7860 端口。需要配置稳定的秘密变量 `BYOK_COOKIE_SECRET` 和实际应用地址 `APP_PUBLIC_ORIGIN`，详细步骤见 [部署说明](docs/BYOK_MODELSCOPE.md)。不要配置作者的模型密钥供访客共用。

密钥配置和对局互相独立；服务重启会清空进程内对局。此仓库包含运行素材，不包含玩家密钥、本机环境、历史对局或私人测试记录。
